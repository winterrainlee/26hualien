# 26hualien

2026년 가을, 화롄에서 보낸 세 달의 경험을 공간으로 기록하는 모바일 웹 지도 시제품.

## Prototype 0.1

- 대만 백지도에서 화롄현 강조
- 화롄현을 누르면 현 단위 화면으로 전환
- 테스트 장소 2곳: 동화대학 후문, 지학역
- 장소를 누르면 테스트 기록을 하단 카드로 표시
- 정적 HTML/CSS/JS + SVG만 사용

현재 지도 윤곽과 장소 위치는 **UI 흐름 검증을 위한 개략 도형**이다. 실제 지리 데이터는 다음 단계에서 공식 행정경계/좌표 데이터로 교체한다.

GitHub Pages 배포 시 저장소 Settings → Pages에서 `main / root`를 선택하면 된다.
